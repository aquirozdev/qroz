# Non-goals

Arc is not trying to own every layer of the stack.

It is not intended to become:

- a new JavaScript runtime;
- a new TypeScript compiler;
- a new package manager;
- another ORM;
- another validation language;
- a proprietary observability backend;
- a Terraform/Pulumi replacement;
- an AI coding agent;
- a universal abstraction that erases provider differences;
- a mandatory microservices architecture;
- an Express-compatibility layer;
- a decorator/reflection-heavy dependency injection framework.

Arc may integrate with these categories, generate inputs for them, or provide thin adapters where that improves application DX.
